# Banque et assurance

Mots-clés : banque, assurance, finance, crédit, microfinance, comptabilité, comptable, mutuelle, sinistre, prêt, épargne, fiscalité

## Pièces comptables en retard dans un cabinet comptable
- Organisation : Cabinet d'expertise comptable
- Interlocuteur : Expert-comptable associé
- Sujet : collecte des pièces
- Situation actuelle : Le cabinet gère une centaine de petites entreprises. Les clients envoient leurs factures en vrac, par e-mail ou sur papier, souvent la veille des déclarations fiscales. Les collaborateurs font des heures supplémentaires chaque fin de mois.
- Demande typique : je veux un espace en ligne pour que mes clients déposent leurs factures
- Besoin réel : Lisser la charge de travail du cabinet en obtenant les pièces tout au long du mois, avec des relances automatiques, pour éviter les retards de déclaration et leurs pénalités.
- Contraintes fréquentes : les données financières des clients sont couvertes par le secret professionnel ; les clients sont de petits commerçants peu équipés ; les pièces doivent être conservées plusieurs années ; les échéances fiscales sont fixes ; le logiciel de comptabilité du cabinet reste la référence
- Outils existants : e-mail, dossiers papier, logiciel de comptabilité

## Dossiers de sinistres incomplets dans une mutuelle
- Organisation : Mutuelle d'assurance
- Interlocuteur : Responsable du service client
- Sujet : déclaration de sinistres
- Situation actuelle : Les adhérents déclarent leurs sinistres par téléphone. Les dossiers incomplets font des allers-retours pendant des semaines et la satisfaction des adhérents a fortement baissé cette année.
- Demande typique : il nous faut une application mobile pour les adhérents
- Besoin réel : Réduire le délai de traitement des sinistres en obtenant des dossiers complets dès la première déclaration, pour regagner la confiance des adhérents.
- Contraintes fréquentes : un audit de sécurité est obligatoire avant la mise en production ; les adhérents âgés doivent pouvoir continuer par téléphone ; les pièces justificatives contiennent des données personnelles ; l'historique des dossiers doit être conservé plusieurs années ; le système de gestion des contrats existant ne sera pas remplacé
- Outils existants : centre d'appels, logiciel de gestion des contrats, courrier

## Impayés détectés trop tard dans une institution de microfinance
- Organisation : Institution de microfinance
- Interlocuteur : Directrice des opérations
- Sujet : application de remboursement
- Situation actuelle : Les agents de crédit rendent visite aux micro-entrepreneurs financés. Les retards de remboursement sont découverts tard, et les agents passent autant de temps avec les clients qui paient bien qu'avec ceux en difficulté.
- Demande typique : je veux une application pour que les clients remboursent par téléphone
- Besoin réel : Détecter tôt les clients en difficulté de remboursement pour que les agents de crédit les accompagnent avant que le retard ne devienne un impayé.
- Contraintes fréquentes : beaucoup de clients vivent en zone rurale avec un réseau faible ; les données financières des clients sont confidentielles ; l'autorité de contrôle exige des rapports réguliers sur les impayés ; les agents travaillent surtout sur le terrain ; le système de gestion des prêts existant reste la référence
- Outils existants : système de gestion des prêts, carnets des agents, téléphone
