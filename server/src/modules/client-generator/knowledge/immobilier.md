# Immobilier

Mots-clés : immobilier, agence immobilière, location, logement, appartement, syndic, copropriété, promoteur, bail, locataire, propriétaire, chantier

## Visites inutiles dans une agence immobilière
- Organisation : Agence immobilière
- Interlocuteur : Directeur d'agence
- Sujet : site d'annonces
- Situation actuelle : Les annonces sont publiées sur plusieurs sites. Les agents passent leurs journées à faire visiter des biens à des personnes dont le budget ou les critères ne correspondent pas, et peu de ventes aboutissent.
- Demande typique : je veux un site pour publier nos annonces
- Besoin réel : Qualifier les acheteurs et les locataires avant la visite (budget, financement, critères) pour que les agents consacrent leur temps aux visites qui aboutissent.
- Contraintes fréquentes : les annonces resteront publiées sur des portails spécialisés ; les agents travaillent surtout en déplacement ; les propriétaires veulent un compte rendu de chaque visite ; les données des clients ne doivent pas être partagées sans leur accord ; la commission n'est perçue qu'à la signature
- Outils existants : portails d'annonces, agenda partagé, téléphone

## Méfiance des copropriétaires envers leur syndic
- Organisation : Syndic de copropriété
- Interlocuteur : Gestionnaire de copropriétés
- Sujet : application pour les résidents
- Situation actuelle : Le syndic gère une quinzaine de résidences. Les résidents appellent pour chaque panne (ascenseur, fuite, éclairage) et des interventions sont oubliées. Les assemblées générales sont tendues et les charges impayées augmentent.
- Demande typique : je veux une application pour que les résidents signalent les pannes
- Besoin réel : Rendre visibles le suivi des interventions et les dépenses de chaque résidence pour restaurer la confiance des copropriétaires et réduire les charges impayées.
- Contraintes fréquentes : beaucoup de copropriétaires sont âgés ; les prestataires d'entretien sont des artisans indépendants ; les comptes doivent être présentés en assemblée générale ; les justificatifs doivent être conservés plusieurs années ; le gestionnaire suit plusieurs résidences seul
- Outils existants : téléphone, tableur des charges, classeurs de factures

## Appels de fonds contestés chez un promoteur
- Organisation : Promoteur immobilier
- Interlocuteur : Responsable commercial
- Sujet : espace client
- Situation actuelle : Les appartements sont vendus sur plan. Les acquéreurs appellent sans cesse pour connaître l'avancement du chantier, contestent les appels de fonds et paient leurs tranches en retard.
- Demande typique : je veux un espace client avec les photos du chantier
- Besoin réel : Faire payer les tranches à temps en reliant chaque appel de fonds à une étape de chantier vérifiable, pour sécuriser la trésorerie du programme.
- Contraintes fréquentes : le contrat de vente fixe les étapes de paiement ; la banque qui finance le programme suit l'avancement ; certains acquéreurs résident à l'étranger ; les photos ne doivent pas permettre d'identifier les ouvriers ; le chef de chantier dispose de peu de temps
- Outils existants : contrats papier, e-mail, tableur des encaissements
