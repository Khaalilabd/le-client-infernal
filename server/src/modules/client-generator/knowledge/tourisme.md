# Tourisme

Mots-clés : tourisme, hôtel, hôtellerie, maison d'hôtes, voyage, agence de voyage, excursion, séjour, circuit, guide, touristes, hébergement

## Doubles réservations dans une maison d'hôtes
- Organisation : Maison d'hôtes
- Interlocuteur : Propriétaire
- Sujet : site de réservation
- Situation actuelle : La maison compte huit chambres, réservées surtout via des plateformes en ligne qui prélèvent une commission. Des chambres ont été réservées deux fois sur deux plateformes, et les clients satisfaits ne reviennent pas directement.
- Demande typique : je veux mon propre site de réservation
- Besoin réel : Synchroniser les disponibilités de toutes les plateformes pour supprimer les doubles réservations, et fidéliser les anciens clients pour qu'ils réservent en direct.
- Contraintes fréquentes : les plateformes resteront la principale source de clients ; la propriétaire gère seule la réception ; les clients étrangers paient souvent par carte ; l'activité est concentrée sur l'été ; la connexion internet de la maison est lente
- Outils existants : comptes sur les plateformes de réservation, cahier des séjours, messagerie

## Informations des participants dans une agence de voyage
- Organisation : Agence de voyage
- Interlocuteur : Directrice
- Sujet : catalogue en ligne
- Situation actuelle : L'agence organise des circuits pour des groupes. Les inscriptions arrivent par téléphone et par e-mail et les listes de participants sont tenues dans des tableurs. Des erreurs de chambres et de régimes alimentaires sont découvertes sur place.
- Demande typique : je veux un catalogue en ligne de nos circuits
- Besoin réel : Fiabiliser les informations des participants (chambres, régimes, documents de voyage) transmises aux hôtels et aux guides, pour éviter les incidents pendant les circuits.
- Contraintes fréquentes : les hôtels partenaires reçoivent les listes par e-mail ; les copies de passeports sont des données personnelles sensibles ; les groupes se constituent souvent au dernier moment ; les guides n'ont qu'un téléphone pendant le circuit ; les prix dépendent de la saison
- Outils existants : tableurs des participants, e-mail, téléphone

## Avis négatifs pour un hôtel balnéaire
- Organisation : Hôtel balnéaire
- Interlocuteur : Directeur de l'hôtel
- Sujet : application pour les clients
- Situation actuelle : Les notes de l'hôtel baissent sur les sites d'avis. Les plaintes (climatisation, propreté, bruit) sont découvertes après le départ des clients, car la réception transmet les problèmes oralement aux services.
- Demande typique : je veux une application mobile pour nos clients
- Besoin réel : Traiter les problèmes des clients pendant leur séjour, avant qu'ils ne deviennent des avis négatifs, grâce à un suivi des réclamations entre la réception et les services techniques.
- Contraintes fréquentes : les clients ne téléchargeront pas une application pour quelques jours ; le personnel ne parle pas toutes les langues des clients ; les équipes travaillent en rotation jour et nuit ; le logiciel de gestion hôtelière existant reste en place ; la haute saison commence dans trois mois
- Outils existants : logiciel de gestion hôtelière, cahier de la réception, talkies-walkies
