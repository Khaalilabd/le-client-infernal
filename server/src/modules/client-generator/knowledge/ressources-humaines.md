# Ressources humaines

Mots-clés : ressources humaines, RH, recrutement, personnel, salariés, employés, paie, congés, intérim, planning, candidats, pointage

## Absences imprévues dans une usine de confection
- Organisation : Usine de confection
- Interlocuteur : Responsable des ressources humaines
- Sujet : gestion des congés
- Situation actuelle : L'usine emploie deux cents ouvrières réparties en équipes. Les demandes de congé se font sur papier et les chefs d'atelier découvrent les absences le matin même. Plusieurs commandes ont été livrées en retard.
- Demande typique : je veux une application de demande de congés
- Besoin réel : Anticiper les absences pour garantir l'effectif minimum de chaque atelier et tenir les délais de livraison des commandes.
- Contraintes fréquentes : une partie du personnel n'a pas d'adresse e-mail ; la convention collective fixe des règles de congés ; la paie est réalisée par un cabinet externe ; les chefs d'atelier n'ont pas d'ordinateur ; les données du personnel sont confidentielles
- Outils existants : formulaires papier, tableur des effectifs, badgeuse

## Candidats perdus dans une société de services informatiques
- Organisation : Société de services informatiques
- Interlocuteur : Responsable du recrutement
- Sujet : plateforme de recrutement
- Situation actuelle : Des centaines de CV arrivent par e-mail. Les réponses prennent des semaines et les meilleurs candidats acceptent d'autres offres entre-temps. Les managers se plaignent de manquer de développeurs.
- Demande typique : je veux une plateforme pour recevoir les candidatures
- Besoin réel : Raccourcir le délai entre la candidature et l'entretien pour ne plus perdre les meilleurs candidats au profit de la concurrence.
- Contraintes fréquentes : les managers techniques ont peu de temps pour évaluer ; les CV sont des données personnelles à conserver pour une durée limitée ; les offres sont publiées sur plusieurs sites d'emploi ; la sélection ne doit pas être discriminatoire ; l'équipe de recrutement compte deux personnes
- Outils existants : boîte e-mail partagée, tableur des candidats, sites d'emploi

## Relevés d'heures en retard dans une agence d'intérim
- Organisation : Agence d'intérim
- Interlocuteur : Directrice d'agence
- Sujet : application de pointage
- Situation actuelle : Les intérimaires remplissent des relevés d'heures papier que les entreprises clientes doivent signer. Les relevés arrivent en retard ou illisibles, la paie contient des erreurs et des intérimaires mécontents partent chez la concurrence.
- Demande typique : je veux une application de pointage pour les intérimaires
- Besoin réel : Obtenir chaque semaine des relevés d'heures validés par les entreprises clientes, pour payer les intérimaires sans erreur et facturer les clients sans retard.
- Contraintes fréquentes : les entreprises clientes refusent d'installer un nouveau logiciel ; les intérimaires changent souvent de mission ; la paie doit respecter le droit du travail ; certains sites interdisent le téléphone pendant le travail ; la facturation est hebdomadaire
- Outils existants : relevés d'heures papier, logiciel de paie, e-mail
